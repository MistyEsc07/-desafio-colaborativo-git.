# Desafio Colaborativo Git: Relatório

  Os cinco integrantes do desafio, decidiram entre si um simples projeto - uma calculadora em *Python*. Foram separados identicamente através de sorteio, o desafio de cada um. A aprovação foi instantânea, não houve oposições menos ainda questionamentos, o grupo se manteve confiante desde o início.

  "Por que uma calculadora?" essa questão foi debatida inicialmente antes de sua aprovação pelos demais integrantes, afinal, a simplicidade de uma calculadora tanto em quesito de programação quanto em apresentação é definitivamente algo a se levar em consideração, afinal, uma calculadora é um objeto básico de ampla popularidade, normalmente sendo utilizada desde a infância de uma pessoa. Entretanto isso serviu apenas como combustível ao grupo, pois a simplicidade tornou a tarefa complexa.
  A linguagem escolhida foi majoritariamente Python. Não é segredo que a linguagem atualmente é a melhor opção para esse tipo de programa, Python oferece uma sintaxe simples e um código limpo, com poucas linhas, já é possível executar o primeiro protótipo de uma calculadora e não demorou muito pro mesmo ser feito.
